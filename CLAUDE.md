# Реинкарнатор — правила работы с кодом

- Страницы **собираются** из `src/` — вручную их не править: Реинкарнатор `reincarnator_sheet_27_psi_cultist_shaman_final.html`
  (`src/index.html`), выбор системы `pages/index.html` (`src/landing/`), Кавалерия `pages/kava.html` (`src/kava/`).
  Правки: шаблоны страниц, `src/styles/*.css`, `src/scripts/**/*.js`; затем `node build.js` (собирает все).
- Системы: адрес `/` — выбор, `/rein/КОД` — Реинкарнатор, `/kava/КОД` — Кавалерия; столы на сервере — система + код
  (SYSTEMS в server.js, GAME_SYSTEM в листе). Старые ссылки `/КОД` сервер ведёт на `/rein/КОД`.
- Перед коммитом и выкладкой: `node build.js --check`. Строка из ошибки на странице → `node build.js --line N`.
- Скрипты — классические `<script>`, куски одного блока склеиваются подряд (общая глобальная область, inline `onclick`).
  Не превращать в ES-модули и не менять порядок файлов в `src/index.html` без причины.
- Тестовый сервер — `PORT=3001 node server.js` (порт 3000 занят сервером пользователя).
- Коммитить `src/` вместе с собранными страницами (и `pages/`): хостинг (Bonto) раздаёт собранный HTML.
- Подробности — README.txt («Для разработчика»), история — CHANGELOG.txt.
