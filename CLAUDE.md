# Реинкарнатор — правила работы с кодом

- Страница `reincarnator_sheet_27_psi_cultist_shaman_final.html` **собирается** из `src/` — вручную её не править.
  Правки: `src/index.html` (разметка), `src/styles/*.css`, `src/scripts/**/*.js`; затем `node build.js`.
- Перед коммитом и выкладкой: `node build.js --check`. Строка из ошибки на странице → `node build.js --line N`.
- Скрипты — классические `<script>`, куски одного блока склеиваются подряд (общая глобальная область, inline `onclick`).
  Не превращать в ES-модули и не менять порядок файлов в `src/index.html` без причины.
- Тестовый сервер — `PORT=3001 node server.js` (порт 3000 занят сервером пользователя).
- Коммитить `src/` вместе с собранной страницей: хостинг (Bonto) раздаёт собранный HTML.
- Подробности — README.txt («Для разработчика»), история — CHANGELOG.txt.
